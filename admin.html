1 · Conexión con GitHub

El token nunca sale de tu navegador: solo viaja a api.github.com. Sin token podés editar y exportar, pero no publicar.
¿Cómo creo el token? (una sola vez)
  1. Abrí github.com/settings/personal-access-tokens/new
  2. Nombre: KENAR admin · Caducidad: 1 año
  3. Repository access → Only select repositories → demo-kenar-web
  4. Permissions → Repository permissions → Contents: Read and write (solo eso)
  5. Generate token y pegalo arriba. Listo para siempre.

¿Cómo tomo las fotos para que se vea bien?
  1. 4–8 fotos: frente, 3/4 izquierda, perfil, espalda, 3/4 derecha.
  2. Fondo liso y luz pareja; misma distancia y altura de cámara.
  3. Prenda centrada y estirada igual en todas las tomas.
  4. JPG, PNG o WebP. Si el iPhone da HEIC, exportá como JPG.
